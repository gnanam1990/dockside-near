## What the page and judge check (testnet, `gnanam1990-dock-escrow2.testnet`)

63 rows: 5 deployment (code hash against the manifest, digest consistency, downloaded contract bytes, deployment
transaction, relayer key scope), 4 config, 28 trade rows over three trades (registration, conservation recomputed
from `get_ledger`, the contract's own flag, funded/released/refunded/held totals, release intent, hold, refund
intents, and transfers out of the escrow against the contract's records) and 26 journey transactions (8 release,
10 hold, 8 refund). The mainnet tab shows **"Not deployed yet"** and sends no request, because
`scripts/proof/sources.json` lists no mainnet run record.

Not checked: who held which key (INV-13), the off-chain documents, and a rebuild of the wasm from source
(`pnpm run contract:reproduce`). The first deployment `gnanam1990-dock-escrow.testnet` (pre-audit build, M24) is not
on the page; the page covers the hardened deployment only.

## Owner steps

1. Push `main` and open the pull request as usual.
2. Enable Pages with GitHub Actions as the source (repository Settings, Pages, Source: GitHub Actions), or:
   `gh api -X POST repos/gnanam1990/dockside-near/pages -f build_type=workflow`
   On a private repository GitHub Pages needs a paid plan, and the published site is public either way.
3. After the next push to `main` the `pages` workflow deploys. Expected address:
   `https://gnanam1990.github.io/dockside-near/` (testnet tab) and `.../#mainnet`.
4. After a mainnet deployment (D2): copy the run's `run-record.json` under `docs/evidence/<tag>/`, add its path to
   `networks.mainnet.runs` in `scripts/proof/sources.json`, run `pnpm run proof:manifest`, commit. For a new testnet
   journey also run `node scripts/proof/record-fixture.mjs` (read-only) and update the row counts in the M46 tests.

## README snippet (for the README stage)

```markdown
## Check it yourself

**Proof page:** https://gnanam1990.github.io/dockside-near/ reads NEAR live in your browser and compares it with
the values this repository expects: the deployed code hash against the build manifest, the contract config, each
trade's ledger with the conservation invariant recomputed, and every journey transaction with an explorer link.
The mainnet tab says "not deployed yet" until a mainnet run record is committed. The page cannot send a transaction.

**One command:**

    pnpm judge

It installs from the frozen lockfile, runs the unit tests and the contract tests, then performs the same read-only
on-chain checks and prints one PASS or FAIL table with the expected value beside every actual value (about two
minutes warm, under four minutes on a fresh checkout; needs Node 22, pnpm 10 and Rust 1.97 with the
`wasm32-unknown-unknown` target). `pnpm judge --only chain` runs only the on-chain part in about ten seconds.

What this proves: the code on chain is the code in the manifest, the escrow's books balance for every trade, and it
paid exactly the accounts and amounts its records say. What it does not prove: who held which key, and the wasm
rebuild from source (`pnpm run contract:reproduce`).
```
