## Real vs simulated vs blocked

- **Real**: every test suite on two operating systems from fresh clones of the committed tree and the frozen
  lockfiles; the compiled wasm executing every call; browser WebCrypto keys and PoP sessions; SQLite persistence; OS
  processes for the API, worker and signers.
- **Simulated**: the NEAR chain (compiled wasm on the M02 host behind the M05 JSON-RPC server), the relayer, funder
  and token-sender wallets, the NEP-141 token, the custody operator, and moved chain time in two browser tests.
- **BLOCKED**: NEAR testnet accounts, deployment, funding, relayer custody, on-chain code hash; 1Click; the funded
  rail.
- **NOT_RUN**: INV-13 acceptance by separate people; manual accessibility review and true 200% zoom; near-workspaces
  tests on the sandbox (none written).
