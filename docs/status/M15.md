## Real vs simulated vs blocked

- **Real**: browser WebCrypto keys and PoP sessions in four contexts, every API route and authority check, SQLite
  persistence, triggers and fenced leases, the compiled escrow wasm executing every refund, release, hold,
  inspection and destination call, the production JSON-RPC clients, the compiled journal engines and worker loop as
  separate OS processes killed with SIGKILL/TerminateProcess.
- **Simulated**: the NEAR chain (and its block time, moved forward +25 h and +24 h on the refund-reasons stack
  only), the NEP-141 token, the funder, sender and relayer signers.
- **BLOCKED**: testnet accounts, deployment and relayer custody (the production worker still exits 78).
- **NOT_RUN**: testnet; INV-13 acceptance by separate people; refund UNKNOWN/RECONCILING/ADJUDICATION in the
  browser; the other modules' payload windows on the contract clock (ADR-0016 follow-up).
