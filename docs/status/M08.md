## What was built

| Area | Implementation |
|---|---|
| API prepare routes | `POST /v1/trade-proposals`, `POST /v1/trade-proposals/review`, `GET /v1/trades/:id/evidence-policy`, `POST /v1/trades/:id/inspection-challenges`; `POST /v1/trades` returns `policyRelay` (services/api/src/trades.ts; `services/api/test/m08-proposals.test.ts`) |
| Signing | `apps/web/src/lib/signing.ts`: digest recomputed by the browser for every prepared payload; refusal on mismatch, unknown purpose or non-canonical value; issuance statement built in the browser and checked against the evidence service |
| Signed-action flow | `SignedAction`: prepare → review (domain, signer and key version, expiry, consequence, digest, exact fields) → sign → record → relay; stays mounted while the state it changes refreshes |
| Screens | Trades list (server values only, risk-first ordering, filters), Create trade (5 steps) and Countersign, workspace tabs Overview, Agreement, Evidence, Release, Payout, Refund, Timeline (+ audit export), Inspections and Payouts lists |
| Local stack | `scripts/local-stack/` (`pnpm run stack`): real API + trade modules + worker/reconciler + isolated attestor/policy services over the simulated chain; control port for invitations, grants, funder deposits and fault switches; relayer for party calls |

## Real vs simulated vs blocked

- **Real**: browser WebCrypto keys and PoP sessions, every API route and authority check, SQLite persistence and
  triggers, evidence parsing and refusals, isolated attestor and policy signer processes, release journal, M05
  outbox worker and reconciler, the compiled escrow wasm executing every call, the production JSON-RPC clients.
- **Simulated**: the NEAR chain (M02 host behind the M05 JSON-RPC server), the relayer and funder wallet (unsigned
  simulated envelopes), chain faults.
- **BLOCKED** (user action needed; nothing here may create accounts or hold keys): NEAR testnet accounts and
  escrow deployment (`scripts/testnet-deploy/README.md`), a relayer with real key custody, a NEP-413 wallet
  connector in the browser, the funded rail (M06).
- **NOT_RUN**: manual assistive-technology review (T-039), true browser zoom/landscape/long translations (T-040),
  any testnet path, INV-13 acceptance with separate people on separate devices.
