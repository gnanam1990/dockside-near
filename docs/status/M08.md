Every data screen calls the real API. Where the running backend has no route yet, the screen shows the API's own
`no such endpoint` answer ("not available in this backend build", with the owning module); no business data,
KPI, seeded trade or browser-computed status is rendered anywhere.

A real defect found by the real-backend run: `/readyz` reports `fundedPayouts: "BLOCKED"` (string); the first
client typing assumed a boolean and would have shown funded payouts as enabled. Fixed: only `"BLOCKED"` is
recognised; any other value renders "Unrecognized funded payout gate" and hides funded controls.
