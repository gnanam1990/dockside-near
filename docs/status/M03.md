## Simulated vs blocked

- Compiled-contract tests run under the M02 simulated NEAR host (`packages/near/test/sim`), not nearcore. Real
  testnet submission of evidence/holds: **BLOCKED** (no testnet accounts or signing allowed in this build);
  the runbook in `scripts/testnet-deploy/README.md` applies, then call `register_evidence_policy`,
  `submit_manifest_attestation`, `submit_inspection`, `set_hold`/`resolve_hold` with the payloads the services
  produce.
- No HTTP endpoints for evidence in M03; the integrated API is M07.
- Object storage is the local content-addressed store; an S3-compatible store is not implemented.
- Hold supersession by a new trade revision is not implemented (documented in ADR-0005).
- INV-13 human acceptance (separate people on separate devices): **NOT_RUN**.

## Handoff for M04+

- Release must require `EvidenceService.currentAttestation` (or the contract's `usable` manifest), a current
  inspector PASS (`currentInspection`), and `HoldService.blocking(tradeId) === 0` / no ACTIVE or
  EXPIRED_UNRESOLVED hold on chain; on release mark the contract `ManifestRecord.consumed`.
- Bind holds and resolutions to `currentAcceptedManifestDigest`, which mirrors the contract's current digest.
- A key rotation, revocation or recovery of any bound role makes `bindingStatus(terms).requiresNewRevision`
  true; attestations and inspections stop being CURRENT until a successor revision is bound.
