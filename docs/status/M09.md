## Real vs simulated vs blocked

- **Real**: HTTP, PoP sessions, request proofs and limits; SQLite persistence and triggers; Ed25519 signatures by
  separately enrolled keys; isolated attestor and policy signer processes; OS processes of the built entry points;
  the compiled contract core (T-041) and the compiled wasm (T-042) executing every call; a fresh clone built from
  the lockfiles.
- **Simulated**: the NEAR chain (M02 host behind the M05 JSON-RPC server) and the relayer that submits party calls.
- **BLOCKED**: testnet accounts, deployment, funding, relayer key custody and the on-chain code-hash check;
  1Click; the funded rail. Exact user steps: [USER-NEXT-STEPS.md](../USER-NEXT-STEPS.md).
- **NOT_RUN**: INV-13 acceptance by separate people, manual accessibility review, true 200% zoom, the UI half of
  T-042, journal-level generated sequences, event recording.
