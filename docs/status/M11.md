## Real vs simulated vs blocked

- **Real**: browser WebCrypto keys and PoP sessions in four contexts, every API route and authority check, SQLite
  persistence, triggers and fenced leases, Ed25519 signatures, the compiled escrow wasm executing every recovery
  call and callback, the production JSON-RPC client for token views and transaction lookups, the worker engine.
- **Simulated**: the NEAR chain, the NEP-141 token and the NFT contract, the token sender's and claimant's
  wallets, the relayer, and (in the last browser test) the chain's block time (+73 h, own stack).
- **BLOCKED**: testnet deployment and accounts; a wallet connector for the sender's own transactions (the UI shows
  the exact call); a relayer signer with real custody (the production worker still exits 78).
- **NOT_RUN**: testnet; real tokens; recovery of assets not attributable to a trade; NFT and multi-token adapters
  (not built by decision, ADR-0014 §6); real OS process kills for the asset engine; manual accessibility review.
