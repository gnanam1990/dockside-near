The `test` job's Linux leg was not replayed with `local-run` on Linux: row 5 runs the same commands (frozen install,
check, contract tests, the Playwright Chromium with its system libraries, the four browser stacks) in
`node:22-bookworm-slim`. The runner-setup steps (corepack, the Rust toolchain) and the three `uses:` steps were not
executed locally; they only provision a fresh runner.

**30-minute question for the chain job.** Locally it took 43.7 minutes, dominated by package downloads at about
100 KB/s during that run (row 5, on the same host an hour earlier, finished a larger reproduction in 13.6 minutes).
The compute in it was about 10 minutes (clean checkout 2 min, wasm rebuild, test crates 2 min, sandbox tests 1 min,
ownership suite 0.5 min). On a hosted runner with a cold cargo cache and fast mirrors it should fit in 30 minutes,
but that is an estimate: no hosted run exists. The job's timeout is 60 minutes; if the first hosted runs come close,
split it into a reproduction job and a sandbox job that downloads the reproduction artifact.
