Payment receipt

Every fact on this receipt is read from the NEAR escrow contract by your browser, and checked there: the contract runs the audited build, the ledger conserves value, the release was approved on the recorded inspection, and the release transaction paid exactly this amount to this account. No server of ours is asked, and this page cannot send a transaction.

What is checked, and what is not

  • Code. The escrow account's code hash equals the audited build in the proof manifest.
  • Trade and parties. Buyer, supplier, payout account, asset and amount are the contract's own records for this trade.
  • Inspection. The inspection recorded on the contract passed, and the release approval names that inspection and that evidence manifest.
  • Payment. A release intent is PAID, the ledger conserves value and shows it released, and the release transaction is final, succeeded, executed this trade's release and transferred the amount to the payout account.
  • Not checked here. Who held which key, the contents of the off-chain documents, and the signature of a downloaded PDF receipt (verify that with pnpm run verify-receipt).
